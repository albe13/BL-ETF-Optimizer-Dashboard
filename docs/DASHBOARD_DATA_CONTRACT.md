## 5. Terminology used consistently in the dashboard

- **Absolute portfolio return**: the strategy's own net return (NAV-based).
- **Benchmark-relative active return**: strategy return minus the Strategic Rebalanced Benchmark return (monthly, arithmetic; annualized × 12 in tables; cumulative as the wealth ratio − 1 in charts).
- **Excess return over cash**: return minus the realized EUR cash return (used in Sharpe/Sortino only).
- **Tracking error**: √12 × std of monthly active returns (realized) — distinct from the optimizer's ex-ante TE under Σ_t.
- **Information ratio**: annualized mean active return / realized tracking error.
- **Decision date**: last common session of the month, signals observed at the close; **execution date**: next common session; **return observation**: the holding period that follows.
